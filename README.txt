ASHISH BASNET — PERSONAL WEB TECHNOLOGY PROJECT

Files:
- index.html: Home
- about.html: About Me
- contact.html: Contact
- style.css: Shared CSS
- script.js: Navigation and form validation

Run:
1. Extract the ZIP.
2. Keep all files in the same folder.
3. Open index.html in a browser.

This version presents the site as a BIT student's learning portfolio, not a fictional company. Replace the example email in contact.html before publishing. The form is a front-end demo only and does not send messages.

Assignment requirements covered: three linked pages, navigation symbols, CSS Grid and Flexbox, external CSS and JavaScript, responsive layout, and JavaScript form validation.
